# Legal Connect AI ⚖️🤖

AI-powered legal platform to connect lawyers and clients in Pakistan. Multilingual (Urdu/English) legal assistant.

## 🌟 Features
- AI Legal Assistant (Urdu/English)
- Lawyer-Client Matching
- Case Tracking & Documents
- Secure Chat & Payments

## 💻 Tech Stack
Next.js | Firebase | OpenAI | Tailwind CSS

## 🚀 Getting Started
1. Clone: `git clone https://github.com/sawanaziz3812/legal-connect-ai.git`
2. Install: `npm install`
3. Run: `npm run dev`
