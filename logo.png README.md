# Legal Connect AI ⚖️🤖
AI-powered platform to connect clients with verified lawyers.

### Features
- Instant AI Legal Assistant (Urdu / English)
- Lawyer-Client Matching
- Legal Document Analyzer
- Secure Chat & Case Dashboard

### Tech Stack
Next.js, Node.js, Python FastAPI, OpenAI, PostgreSQL

### Quick Start
git clone https://github.com/username/legal-connect-ai.git
cd legal-connect-ai
npm install
npm run dev

### Vision
Making legal help affordable and accessible in Pakistan.
